# PROG101_Assignment_Matthew-Junior-Boima_905005787
Digital Patient Queue and Triage Priority System

Project Overview

A proposed system designed to improve patient registration and queue management in health centres across Sierra Leone by prioritising patients according to medical urgency.

Objectives

* Improve patient registration.
* Identify emergency patients.
* Reduce waiting times.
* Organise patients by priority.
* Generate daily patient reports.

Priority Levels

1. Emergency – Priority 1
2. Urgent – Priority 2
3. Routine – Priority 3

Main Features

* Patient registration
* Age and temperature validation
* Automatic priority calculation
* Ticket generation
* Queue management
* Daily reports

Tools Used

* Flowgorithm
* Algorithms
* Pseudocode
* Flowcharts
* GitHub

SDG Alignment

* SDG 3: Good Health and Well-being.
* SDG 9: Industry, Innovation and Infrastructure.
* SDG 10: Reduced Inequalities.

Conclusion

This project demonstrates how programming concepts can help solve healthcare challenges in Sierra Leone by improving patient prioritisation and queue management.
